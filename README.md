# 频谱工作台（通信工程教学 · 离线简化模型）

用于比较一组载波频率配置的教学工具：录入少量载波、保护间隔与**每日激活区间（本地挂钟时间
+ 显式 UTC 偏移，可跨午夜）**后，绘制频段占用与发射谱，按**同一时刻实际在发射的载波**
检查 **频带重叠、保护带不足、掩模尾部越界**——频率相同但时间不重叠的载波不互相干扰；
在**线性域 (W)** 汇总功率后以 dBm 显示；极化复用由输入规则决定（禁止 / 允许 / 隔离度未知
待评估）；并可用 **OR-Tools CP-SAT** 为载波寻找一组满足间隔的频率位置。规划可保存并
**绑定场景修订与时间窗口**，场景时间/频率/规则被改后旧规划自动标为过期、拒绝直接复用。

> ⚠️ 纯离线简化模型：**不连接无线电设备，不生成任何发射指令**。掩模与发射谱均为教学
> 用平顶 + 折线衰减的简化数值，不对应任何标准或真实设备指标。

## 快速开始

需要本机 PostgreSQL（或修改 `DATABASE_URL`）。提供一个 conda 方式安装的便捷脚本：

```bash
# 1) Python 依赖
pip install -r backend/requirements.txt

# 2) 前端依赖
cd frontend && npm install && cd ..

# 3) 初始化数据库并写入示例掩模 + 教学演示场景
python -m app.seed          # 工作目录为 backend/，或设置 PYTHONPATH

# 4) 启动
( cd backend && uvicorn app.main:app --reload --port 8000 )
( cd frontend && npm run dev )        # http://localhost:5173 ，/api 代理到 8000
```

环境变量：`DATABASE_URL`（默认 `postgresql+psycopg2://postgres@127.0.0.1:5432/spectrum`）、
`CORS_ORIGINS`。

## 计算模型要点

### 0. 激活区间与时间口径（`backend/app/services/time_model.py`）

每个载波可带若干**每日循环**激活区间，区间用本地挂钟 `HH:MM` + **显式 UTC 偏移**表达：

- 半开区间 `[start, end)`：起点含、终点不含；相邻区间（一个 10:00 止、另一个 10:00 起，
  含跨午夜处在 00:00 的衔接）**不算重叠**；`end='24:00'` 等同次日 00:00。
- **跨午夜**：终点早于起点（如 `22:00–02:00`），表示到次日终点止。
- 区间先换算到 UTC 绝对分钟再做重叠判断，因此不同 UTC 偏移的两段“本地白天”天然错开。
- 一个载波自己的区间**不得互相重叠**（首尾相接允许），API/前端都会拒绝。
- **区间列表为空 = 始终激活（always-on）**：这是旧无时间数据升级后的唯一默认语义；
  启动时轻量迁移只加列、回填指纹，不改历史数据与历史分析结论。

分析与规划支持两种口径（请求里的 `at` 字段）：

- **全天口径**（不给 `at`）：只要两个载波在一天循环中存在共同激活时刻才参与检查；
  时间完全不重叠的载波对登记为 `time_separated_pairs`，不报任何几何/泄漏冲突，
  规划中也不加频率间隔约束（可同频）。
- **时刻口径**（给带时区偏移的 ISO-8601，如 `2026-10-01T19:30:00+08:00`，
  naive 时间一律拒绝）：只评估该时刻实际激活的载波；频段图把未激活载波灰显（💤），
  发射谱与功率汇总只叠加激活载波。

### 1. 冲突检查（`POST /api/analyze`，结果含 bands / spectrum / findings / power_summary / time_context）

- **频带重叠 overlap**：两频带边缘净距 `gap = max(low) − min(high) ≤ 0`，报重叠量。
- **保护带不足 guard_shortfall**：`0 < gap < guard_required_mhz`，报净距与缺口。
- **掩模尾部越界 mask_tail（有方向）**：发射机掩模谱落入受害载波频带的功率
  `P = ∫_victim 10^(PSD_dbm/10)·1mW df`（PSD 在线性 W/Hz 域积分），超过限值即报；
  因功率/掩模不同，A→B 与 B→A 分别计算、分别定位。
- **极化复用规则**（针对异极化对）：
  - `forbidden` 禁止：重叠即冲突；
  - `allowed` 允许（已知隔离度足够）：可同频，不报几何/泄漏冲突；
  - `unknown` 待评估：重叠只提示“隔离度未知，复用待评估”，不下违规定性；
  - 同极化对无极化隔离，始终按禁止处理。

### 2. 功率汇总

dB 是对数尺度，**不能直接相加**。先换算
`P_W = Σ 1mW · 10^(p_i/10)`，再 `P_dBm = 10 log10(P_W/1mW)`。
响应里同时给出错误的“dBm 直接求和”数值供课堂对比（例如多个载波 275 dBm vs 正确 36.14 dBm）。

### 3. OR-Tools 规划（`POST /api/plan`）

CP-SAT 在 1 kHz 网格上为每个载波选中心频率，约束：

- 落在给定可用频段内；
- **时间口径**：全天口径只对“一天内存在共同激活时刻”的载波对加约束，时刻口径只约束该
  时刻同时激活的载波对；排程互不重合（含跨午夜首尾相接、不同 UTC 偏移错开）的载波对
  允许同频，`pair_constraints` 中标记为 `time-separated`；
- 需要隔离的载波对（同极化 / 禁止 / 待评估）通过布尔析取排序，
  满足 `中心距 ≥ 半宽_i + 半宽_j + 要求边缘净距`；
- 允许复用的极化对不加约束（可同址）；
- `guard_only`：统一用保护间隔；`mask_aware`：对每对载波按**双向**掩模泄漏都不越限
  反算所需净距（含 0.5 dB 规划裕量，保证返回方案在分析口径下必然达标）；
- 目标：最小化相对录入位置的总偏移。无解时返回 `INFEASIBLE` 与放宽建议。
  返回中带 `post_check`（对方案按**同一时间口径**重跑完整分析）。

### 4. 场景修订与已保存规划（`/api/plans`）

- 场景带 `revision`（内容实际变化才 +1，相同内容重复保存不递增）与内容 `fingerprint`
  （规范化 JSON 的 SHA-256，含全部载波时间区间）。
- `POST /api/plans` 按当前场景**重新求解并强制 post-check** 后落库，记录场景修订、指纹、
  `scope`（`anytime` / `instant`）与绑定的 UTC 时刻。
- 读取时实时比对当前场景：修订或指纹不一致即 `stale=true` 并给出原因；
  `POST /api/plans/{id}/recheck` 对过期规划返回 `usable=false`（**拒绝直接复用**）。
  编辑时间导致过期后，重新求解即可得到通过 post-check 的新方案。

## 教学演示场景（种子数据）

1. **教学演示场景**（12 个载波，全部始终激活，复现原有静态冲突，历史结论不变）。
2. **时间复用演示**（5 个载波）：

| 载波对 | 静态频率图 | 时间安排 | 时间口径结论 |
|---|---|---|---|
| T1(30 dBm,loose,+8) / T2(20 dBm,loose,+8)，净距 0.5 MHz | 保护带不足 + 双向尾部越界 | 08:00–20:00 / 20:00–08:00（跨午夜，首尾相接） | 不重叠时段零冲突；把任一段延长 1h 后在重叠时刻同时出现保护带不足与方向性泄漏 |
| T3(+8) / T4(+0)，同频 160 MHz | 频带完全重叠 | 各自本地 08:00–16:00 | UTC 轴上 00–08 / 08–16 完全错开，无冲突 |
| T5 | 远离其余载波 | 区间为空（始终激活，旧语义） | 任意时刻都干净 |
